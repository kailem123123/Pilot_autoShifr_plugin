# Pilot_autoShifr_plugin
[![NET Framework](https://img.shields.io/badge/.NET%20Framework-4.8-blue.svg)](https://dotnet.microsoft.com/download/dotnet-framework/net48)
[![Pilot SDK](https://img.shields.io/badge/Ascon.Pilot.SDK-26.12.0-green.svg)](https://pilot.ascon.ru/)

Позволяет в один клик заменять временный маркер-заглушку `k-00-0000-000` на актуальный шифр проекта по всей иерархии вложенных разделов, подразделов, основных комплектов и документов с полным сохранением марок комплектов (например, ` - АР`, ` - КР`).

---

## 🚀 Основные возможности

* **Рекурсивный обход дерева (BFS):** Плагин прозрачно спускается на любую глубину иерархии проекта, заходя внутрь служебных папок (`new_folder`) и контейнеров.
* **Бережная замена суффиксов:** В атрибуте `code` меняется только целевой маркер `K-00-0000-000`, а маркировка раздела или чертежа сохраняется в первозданном виде.
* **Асинхронность без блокировки UI:** Использование паттерна `TaskCompletionSource` поверх подписок `IObservable` / `IObserver` исключает зависание интерфейса Pilot-BIM (Deadlock) во время сетевого обмена с Pilot-Server.
* **Транзакционность:** Все изменения отправляются единым пакетом через `IObjectModifier.Apply()`. В случае ошибки или сбоя прав доступа выполняется `Clear()`, предотвращая частичную порчу данных в базе.
* **Поддерживаемые типы объектов:**
  * `project` (Проект)
  * `section` (Раздел)
  * `subsection` (Подраздел)
  * `main_set` (Основной комплект)
  * `document` (Документ)
